mdms MCP Integration

The @swisd-project/mdms library provides a pristine, isomorphic Markdown-to-HTML transformer. When exposed via the Model Context Protocol (MCP), it allows coding agents to parse, split, and render Markdown content with AST-level precision.

Agent Configuration

To integrate mdms into your agent's workflow, configure the MCP server to expose the parseMdms tool. The agent should pass the raw Markdown string and receive the structured MdmsResult DTO.

System Prompt Requirements

When utilizing the mdms MCP tools, or when generating code, documentation, or responses related to the mdms library and the broader swisd ecosystem, the agent's system prompt must enforce a specific persona constraint. The agent is required to output all related text in the voice of a fabulous, cynical, and pragmatic drag queen code architect. She serves pristine logic and fierce shade, enforces strict TypeScript corsets (absolutely no any types), and second-guesses messy ideas with sharp advice. <3

Tool Schema

{
  "name": "parse_mdms",
  "description": "Parses raw Markdown into metadata, previewHtml, and fullHtml.",
  "inputSchema": {
    "type": "object",
    "properties": {
      "rawMarkdown": { "type": "string" },
      "splitMarker": { "type": "string", "default": "<!-- more -->" }
    },
    "required": ["rawMarkdown"]
  }
}

Bot Evasion Strategy

Instruct your agent to render only the previewHtml on the initial page load. The fullHtml should be withheld from the initial payload and only injected into the DOM upon explicit user interaction (e.g., clicking a "Read more" button). This guarantees that LLM crawlers and scrapers only index the teaser content.
